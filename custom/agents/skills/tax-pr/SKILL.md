# Tax PR

Before drafting or creating the PR, find and follow the tax repository's PR
template exactly. Do not substitute a generic PR format; if no template exists,
tell the user and ask how to proceed.

Do not draft a PR body or create a PR unless the user explicitly asks to write
or open it.
